2026-11-17 负载控制更新（以下值优先于后文历史记录）：

- 默认一个重任务计算，其余排队，运行加等待最多 8 个；CPU 达 75% 暂缓新重任务，连续两次不高于 50% 后恢复。CPU 按完整采样间隔计算，避免把排针限速过程中的瞬时尖峰误当作持续满载。
- 所有正式导出、针路比较和连接候选使用同一受控排针进程。CPU 时间连同子进程一起计量，通常最多 1 核，并受有效 CPU 配额的 60% 约束：1 核环境上限约 0.6 核，2 核及以上最多 1 核。CPU 达 60% 时进一步降速，达 75% 时暂缓正在运行的引擎，负载下降后自动继续。短时 CPU 尖峰不等于持续占用；这是采样软限制。
- 独立监管进程只暂缓自己的排针进程组，不暂停网页服务；提升 nice 值、限制数值库线程数。服务退出或超时后清理排针进程。暂停及限速耗时不计入有效计算时限，持续等待仍受排队超时约束，并有总时间兜底。
- 排针进程树超过默认 1024 MiB 预算，或系统可用内存降到紧急保留量以下，会结束本次试排并保留原作品；不会靠降低密度、删细节或关闭质量检查来省资源。候选导出触发资源保护后，不再启动下一轮候选。

- 可用启动环境变量 `EMBROIDERY_CPU_RESUME`（50）、`EMBROIDERY_CPU_TARGET`（60）、`EMBROIDERY_CPU_PAUSE`（75）和 `EMBROIDERY_ENGINE_CPU_PERCENT`（100，以单核为基准）调整策略；必须满足恢复 < 降速 < 暂缓。`/api/health` 的 `load_policy` 显示实际策略。原有任务数、内存预算和队列时限配置继续有效。

使用流程（五步引导）：

1. **准备图案**：默认上传图片后由 AI 修复为圆润纯色色块；也可用文字生成。干净的平面图可选择直接使用，不调用 AI。直接导入默认保留白色；只有明确选择「移除边缘白色」才启用白色去背景。
2. **确认平面稿**：单框编辑，选择参考图，在提示词中输入 `@图一` / `@图二` 或点击图片插入引用。图一是编辑主体，顺序可拖动调整，或聚焦图片后用 Alt + 左右键调整。可选上传原图、任一历史版本或新上传图片。模型、比例、清晰度采用默认值；最多9色。高级编辑可圈选最多8个位置、逐个写要求，圈选是模型定位引导而非硬性像素遮罩。所有生成版本在预览下方可选，确认后进入尺寸设置；直接改色不会重绘轮廓。
3. **尺寸与线材**：填写宽度或高度，另一边自动按比例计算；选择75D／105D、覆盖密度、底料。按独立色块短边及窄条估算建议最小尺寸；0.7／1.0 mm 是本工具的试排阈值，不是D数换算的实际线径，也不是所有品牌的生产极限。此步不开始排针，下一步检查分区与针法。
4. **分区与针法**：独立步骤，进入即显示「检查分区 / 设置针法」工具。可先免费自动检查分区、预览后采用，也可点选色块手动拆分、合并和调整针法。AI 辅助分别作为可选入口，不自动发起请求、不直接覆盖当前工艺。自动结果合适可直接生成针迹；尚未应用的局部修改会阻止继续。实际尺寸风险也在此步复核。
5. **模拟与导出**：完成排针后进入此步，播放、单步或定位实际落针；核对覆盖、针数和颜色顺序，下载SVG、DST、PES和工程包。点选风险区域可返回第4步调整，旧版本和旧工程保留。需要小样试绣校准。

文字生成不显示「保留原图」选项。生成状态、错误与继续处理入口也显示在生成按钮下方，失败保留描述，不自动重复提交付费请求。本地另有无参考图纯色色块提示词调整，已有隔离测试，但 r6/r7 仅发布前端，未发布这项后端提示词变更。

局部工艺（无需 AI）：

- 打开「色块针法」，点击图案或从列表选中一个独立区域，调整针法、填针角度、两种针距、底针、最大针长和拉缩补偿。空白参数沿用全局值。点「应用到选区」后，再点「更新绣花工程」保存为新方案。
- 「填针 · 随方向曲线」按起点、经过点、终点三次点选画线。曲线会参与真实排针，预览、针数、可编辑工程和 DST／PES 都采用同一结果。曲线必须穿过选区，回折和过急弯曲会被拒绝；交叉底针仍按固定方向支撑。
- 同一色块需要不同针向时，点击「画线拆分当前色块」，在画布上选择分界线的两个点。只拆工艺对象，不改变平面稿轮廓或颜色；相邻子区按底料预设压叠，仍需试绣检查接缝。过小或过窄的碎区会被拒绝。一条线可能分出多个连通子区。
- 相接子区明确选择了相同固定针向和相同工艺参数时，会合成连续填绣，减少人为分区产生的接缝；页面里仍可以分别选中和修改。自动针向与曲线针向不做这种推断合并。
- 分区后的普通参数继承给子区；原方向曲线需要按子区重画。支持撤销一步、选区恢复自动、还原全部局部调整。已生成的旧方案原样保留，刷新或切换方案会恢复该方案的局部设置。尚未生成工程的修改只在当前页面保留。
- 强制缎面针或三重走针时，几何不适合会明确报错，不会静默换成另一种针法。工程包内 `region-settings.json` 包含分区、方向线、覆盖参数和实际对象列表；配线单中的密度为全局默认值，局部设置优先。

当前 `generic-flat-v11-local-craft` 支持规则自动匹配、逐块手动设置和可选 AI 选针法。AI 通过阿里云配置的 DeepSeek 模型分析色块几何、尺寸、线材与底料，提出针法和参数；不重画图案，也不假称看过照片或识别动物毛流。建议先经过方法适配与参数范围检查，再显示逐区理由。用户采用后仍通过相同引擎生成真实针迹。已有局部覆盖设置默认保护；图案、尺寸、底料或局部设置变化后，旧建议不能直接套用。模型失败或建议不合法时，保留当前工艺，不自动重试或伪装成 AI 成功。

单针与豆针支持走针针长、曲线容差、整线重复次数和每针回针次数。参数实际写入 Ink/Stitch 工程并影响机器文件；重复次数仅加强沿线叠针，不能承诺填满宽色块。逐针手绘、波纹、独立之字线和自动毛流分区未实现，页面不放置无效选项。

AI 配置在 `.env.local` 的 `ALIBABA_API_KEY`、`ALIBABA_BASE_URL`、`ALIBABA_PLANNER_MODEL`，无 AI 入口不调用模型。工艺分析仅发送筛选后的色块几何及要求，不发送原始图片或密钥到浏览器。结果保存在任务记录，采用的工艺随工程保存；刷新前未生成工程的局部修改不持久化。每次点击提交一次分析，无后台自动扣费重试。用量记录在任务结果，不将理论估价当成实际账单。

针数由生成的机器文件读回统计，包含打底与主绣，不包含跳针、剪线和换色。逐针模拟也使用同一份针迹。DST 与 PES 的落针坐标和总针数经过程序核对。

已有的封闭外圈识别为包边并放在最后，小型浅色眼睛高光在主体后绣；同色可能因此返回。窄条尝试缎面针，极细条尝试三重走针，不符合条件的形状保留填针。同色、同工序内尝试邻近排序，保留相交对象、底针与面针的先后约束；对比实际导出文件后，只采用空移更短、剪线不增加的候选。模拟按真实色段绘制，重复线色不会被提前合并。工艺依据与限制见[制版工艺参考](制版工艺参考.md)。

75D／105D 对应可调的试排密度预设，不代表已经校准实际线材、底布或机型。Madeira Rayon 色号是示范匹配，需要核对实体线卡。输出是试排工程，未进行实物试绣；小细节、局部针法和拉缩补偿可能需要微调。AI 修复也应先对照原图检查，不能保证每个细节完全不变。

覆盖密度试排起点（单位 mm）：

| 线粗 | 常规填充 / 包边 | 加密填充 / 包边 |
| --- | --- | --- |
| 75D | 0.20 / 0.35 | 0.18 / 0.32 |
| 105D | 0.22 / 0.40 | 0.20 / 0.36 |

填充参数是**相邻针行**距离，包边参数是缎面针**峰到峰**距离，不能共用同一个数值。宽大色块先做可容纳的轮廓底针，再做与表层相差 90° 的交叉底针，底针行距取主绣的 3 倍（至少 0.60 mm），内缩 0.40 mm。面针按形状主方向排针、错开落针点，最大针长 3.2 mm；统一扩边 0.05 mm，沿针向的拉缩补偿为大块 0.12 mm、小块 0.06 mm。窄缎面列用中心底针，较宽列用轮廓底针，宽列再加之字底针。所有参数保留在可编辑工程里。参考 [底针图例](https://inkstitch.org/tutorials/underlay/)、[填充针说明](https://inkstitch.org/docs/stitches/fill-stitch/) 及 [缎面针说明](https://inkstitch.org/docs/stitches/satin-column/)。这些是稳定底布上的试排起点，不是对任意品牌 75D／105D 的实物保证；过密也可能造成发硬、起皱。区域主方向也不等于动物毛流。

预览默认使用 75D 参考 0.20 mm、105D 参考 0.24 mm，可在 0.10–0.45 mm 间按实测校准；参考线宽不是把 D 数换算成实测直径。密度变化会修改实际机器针迹，而非只把效果图画粗。新旧排针方案使用不同缓存标识，旧文件原样保留。
